## ✨ Why EnglishRepo?

Most English resources do one of two things: they drown you in rules, or they promise fluency in 3 days.
**EnglishRepo does neither.**

It gives you small, clear, finishable steps, and then it lets you *hear*, *read* and *say* real English, the way people actually use it.

> Built by a web developer with an oddly strong obsession with the English language, for anyone who wants to get better at it. Mistakes welcome.

## 🚀 What you'll find inside

### 📘 Grammar: from zero to confident
A structured path from **A1 to A2**, with short lessons that explain one idea at a time, with examples and visuals.

| Level | What you'll master |
|---|---|
| **Level 1 (A1)** | Present Simple & prepositions of time · Singular/plural nouns & imperatives · Possessives & *have got* · Question words & adverbs of frequency · *There is / There are* & quantifiers · Present Continuous |
| **Level 2 (A2)** | Present Simple vs Continuous · Comparatives & superlatives · Past Simple (+ irregular verbs) · *Be going to* · *Will* · Present Perfect |

Each lesson is split into bite-sized sections (affirmative, negative, questions, short answers...) so you never face a wall of text.

### 🎧 Extra: where English comes alive
This is the part that textbooks can't give you.

- **🎬 Video fragments with translation.** Watch a real clip *first* with no help, then read the translation to check what you understood. It's listening practice that actually trains your ear.
- **👅 Tongue twisters.** Fix your pronunciation and build fluency by repeating the classics, from *Peter Piper* to the *woodchuck*.
- **📖 Quotes with context.** Read real passages (from literature like *1984* to pirate history) and tap the highlighted words to see what they mean **in that exact context**, not just in a dictionary.

## 🛠️ Run it locally

```bash
# 1. Clone the repo
git clone https://github.com/Gonzalocapelari/english_repo
cd english_repo

# 2. Install dependencies
npm install

# 3. Start the dev server
npm run dev
```

Then open **http://localhost:3000** and you will see the whole thing.

### Tech stack

- **Next.js 16** (App Router) for fast, file-based routing
- **React 19** for the interface
- **TypeScript** (strict) for safe, predictable code
- **Tailwind CSS 4** plus hand-written CSS for a custom look
